# מסד הנתונים (Supabase)

- `schema.sql`: **המסד המלא**. בטוח להרצה חוזרת (יוצר רק מה שחסר). בהתקנה חדשה, או כשבדיקת ההתקנה מראה חוסר, מריצים אותו כולו.
- `updates/`: השינויים הקטנים מאז החבילה האחרונה, לפי מספר החבילה. כל שינוי נכנס גם לסוף `schema.sql`.

## בדיקת התקנה
במסך **תצוגה ומצב** (מנהל שירות, במצב ענן) מופיע כרטיס "בדיקת התקנה". הוא משווה את המסד החי לרשימה ב-`js/schema-expected.js`.

אחרי כל שינוי ב-`schema.sql` מריצים `bash scripts/gen-schema-expected.sh` (Postgres מקומי) ומעדכנים את `js/schema-expected.js` באותו PR.

## בדיקות
`tests/`: בדיקות Playwright במצב הדגמה (`node tests/run-all.mjs`), בדיקות SQL ב-`tests/sql/`.
בדיקות שצריכות קובץ אמיתי של לקוח (stage20, stage30) מחפשות אותו ב-`tests/private/`, שלא נכנס לריפו (הריפו ציבורי). בלעדיו הן מדולגות.
