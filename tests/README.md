```
npm install
npx playwright install chromium
node tests/run-all.mjs              # הכל
node tests/run-all.mjs stage7.mjs   # קובץ אחד
```

## קבצים פרטיים
`tests/private/` לא נכנס לריפו (הריפו ציבורי). בדיקות שצריכות קובץ אמיתי מדולגות בלעדיו:
- `stage20.mjs` צריכה את `tests/private/fitout-sample.json` (ייצוא ממערכת התמחור)
- `stage30.mjs` צריכה את `tests/private/pricing-sample.xlsx` (טבלת תמחור)
